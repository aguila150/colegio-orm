Instrucciones para correr el proyecto

Desde terminal
-Entrar a la carpeta del proyecto
-Crear entorno virtual con:
 python -m venv .venv
-Activarlo:
 source .venv/bin/activate 
-Instalar dependencias  
 pip install python3 
 pip install sqlalchemy
-Correr el proyecto 
 python3 seed.py
